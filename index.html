MANUAL COLLECTION / GITHUB ACTIONS

Connect your scanner.

Use your repository's GitHub Actions workflow to collect jobs on demand and follow live source progress here.

Starting scans requires Actions write access. Live source details also require Checks read access; private repositories need a compatible GitHub App token or classic token with repository access. A fine-grained personal token can start scans even when it cannot read Checks. Your token is held only in this tab's memory and sent directly to GitHub. It is cleared on disconnect, sign-out or page reload.

Open GitHub Actions

You can also start the workflow from GitHub's Run workflow menu. Collection respects each source's polling limits. Disconnecting stops monitoring here; a scan already running on GitHub continues.
